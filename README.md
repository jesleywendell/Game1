# OATHBREAKER

**Action RPG 2D Isométrico — Dark Fantasy Roguelite**

Projeto acadêmico desenvolvido em Godot 4.6 (GDScript, GL Compatibility) para a disciplina de Introdução ao Desenvolvimento de Jogos — iCEV.

## Gênero
Action RPG 2D com perspectiva isométrica, combate em tempo real com lança e habilidades divinas corrompidas, sistema de progressão roguelite com fragmentos da alma.

## Controles
| Ação | Tecla |
|------|-------|
| Mover | W/A/S/D |
| Dash | Espaço |
| Ataque básico | Mouse Esquerdo |
| Golpe Sagrado (Q) | Q |
| Lança Divina (E) | E |
| Pausar | ESC |

## Estrutura
- `scripts/` — código GDScript (25 scripts)
- `scenes/` — cenas Godot (.tscn)
- `assets/` — sprites, tiles, UI, áudio
- `docs/` — especificações e planos de implementação
- `gdd.md` — Game Design Document completo

## Executar
Abrir o projeto no Godot 4.6 (Compatibility renderer) e pressionar F5.
